# Technical Specification: ES_Combinations Catalog

This document details the structure, mathematical definitions, and schema of the **`ES_Combinations.csv`** deliverable generated by the TME Analysis Platform.

---

## 1. Overview & Concept: Exact Sign Sequences (ES)

An **Exact Sign Sequence (ES)** represents a recurring, coordinated protein signature where each participating biomarker exhibits a fixed regulatory direction:
- `(+)` indicates overexpression / positive loading in the process tail ($G+$).
- `(-)` indicates targeted repression / negative loading in the process tail ($G-$).

To prevent redundant combinations under eigenvector inversion ($G \times L^T = (-G) \times (-L)^T$), all signatures are canonically normalized:
$$\text{ES} \equiv -\text{ES}$$

---

## 2. Table Column Schema

The `ES_Combinations.csv` file records every candidate signature mined from the dataset across lengths 3 to 8:

| # | Column Name | Data Type | Description |
|---|:---|:---:|:---|
| 1 | `Combo_ID` | String | Unique identifier for each candidate signature (`Combo_1`, `Combo_2`, ...). |
| 2 | `Length` | Integer | Number of biomarker proteins participating in the signature (range: 3 to 8). |
| 3 | `Frequency_Count` | Integer | Total number of process vectors ($G$) matched by this signature. |
| 4 | `In_2+_Gs` | Boolean | `True` if the signature recurs across $\ge 2$ process vectors; `False` if it is a private singleton. |
| 5 | `Exact_Sign_Sequence` | String | Alphabetically ordered, canonical protein sign sequence (e.g., `CD3(+) \| CD8(+) \| PD1(+)`). |
| 6 | `Covered_G_Vectors` | String | Semicolon-delimited list of all matching process vectors ($G$). |

---

## 3. Mathematical Definitions & Mining Methodology

### Combinatorial Enumeration
For a process tail containing $N$ significant proteins, all subsets of size $k \in [L_{min}, L_{max}]$ are enumerated:
$$\binom{N}{k}$$

Each candidate subset is converted to its canonical representation:
1. Biomarkers are sorted alphabetically.
2. If the first biomarker has a negative sign (`-`), all signs in the subset are inverted.

### Recurrence Classification
- **Singletons (`In_2+_Gs = False`):** Signatures appearing in only one vector ($G$). Singletons are considered noise or sample-specific idiosyncrasies and are excluded from greedy Set Cover optimization.
- **Shared Modules (`In_2+_Gs = True`):** Signatures recurring in two or more independent process vectors. These form the eligible candidate pool for optimal module selection.
