רקע — Surprisal Analysis, G ו-L

Surprisal Analysis הוא אלגוריתם המפרק מטריצת ביטוי חלבוני (כאן: נתוני IMC) לרכיבים ביולוגיים עצמאיים באמצעות פירוק SVD (Singular Value Decomposition). האלגוריתם מיושם בנפרד על כל סקשן (ROI).

שתי המטריצות המרכזיות

מטריצהממדיםתיאור
G — וקטורים עצמיים חלבונים × רכיבים כל עמודה G0, G1, G2... מייצגת "תהליך ביולוגי" — דפוס הביטוי של החלבונים באותו תהליך
L — מקדמים תאים × רכיבים כל שורה מייצגת תא בודד; הערכים הם "עוצמת" כל תהליך ביולוגי באותו תא

הרעיון המרכזי: הדאטא המקורי (בסקאלת log) ניתן לשחזור על ידי כפל המטריצות:

X_log  =  G  ×  Lᵀ
כאשר משתמשים בכל הרכיבים, השחזור מדויק מתמטית (SVD מלא). השאלה המעניינת היא: כמה רכיבים מספיקים כדי לייצג את הדאטא היטב?

האלגוריתם החמדן — תוצאות

האלגוריתם החמדן מוצא קבוצה מינימלית של ~88 רצפי ES (Exact Sequences — קבוצות חלבונים ייחודיות) המשותפים ל-120 הסקשנים, ומכסים את מרבית וקטורי ה-G בכל סקשן.

לכל סקשן, בטבלת Best_Combination_Details, מצוין אילו עמודות G נבחרו — למשל G2, G5, G9. אלו הרכיבים שה-ES האופטימלי "מייצג" עבור אותו סקשן.

שאלת המפתח: עד כמה הייצוג המינימלי הזה (~88 ES במקום כל הרכיבים) שומר על המידע הביולוגי המקורי? זהו בדיוק מה שמדד ה-R² בא לכמת.

מדד R² — הרעיון והנוסחה

R² (מקדם הדטרמינציה) מודד כמה טוב שחזור מסוים מייצג את הדאטא המקורי:

R²  =  1  −  ( SSres / SStot )
מונחנוסחהפירוש
SSres — שגיאת השחזור Σ(xᵢ − ŷᵢ)² כמה שגינו — הפרש בין הדאטא האמיתי לשחזור, בריבוע
SStot — שונות כוללת Σ(xᵢ − x̄)² כמה שונות יש בכלל בדאטא האמיתי

ערכי R² אפשריים

  • R² = 1 — שחזור מושלם, המודל מסביר את כל הדאטא
  • R² = 0 — המודל לא טוב יותר מסתם לקחת את הממוצע
  • R² שלילי — המודל גרוע מהממוצע

שני ה-R² שמחשבים לכל סקשן

R²_full — Baseline

שחזור הדאטא עם כל רכיבי ה-G וה-L של הסקשן (G0, G1... עד G38). עונה על השאלה: עד כמה ה-Surprisal Analysis בכלל מסביר את הדאטא של סקשן זה?

X̂ = G_all × L_allᵀ  →  R²_full

R²_optimal — הייצוג המינימלי

שחזור הדאטא עם רק הרכיבים שנבחרו ע"י האלגוריתם החמדן לאותו סקשן. למשל, אם נבחרו G2, G5, G9 — משתמשים רק בשלוש העמודות הללו מ-G ומ-L:

X̂ = G_selected × L_selectedᵀ  →  R²_optimal

ΔR² — מחיר הקומפרסיה

ΔR²  =  R²_full  −  R²_optimal

ΔR² מודד כמה מידע ביולוגי "מאבדים" כאשר עוברים מהייצוג המלא ל-88 ה-ES בלבד. ככל שΔR² קטן יותר — האלגוריתם שמר יותר מידע.

R² מחושב לכל תא בנפרד ואז מוצע ממוצע על פני כל התאים בסקשן. כך מקבלים ערך יציב שמייצג את הסקשן כולו.

חישוב R² — שלב אחר שלב

עבור כל אחד מ-120 הסקשנים:

שלבפעולהפרטים
1 טעינת נתונים קרא G.xlsx, L.xlsx, וקובץ הדאטא המקורי של הסקשן
2 הכנת X_log חלץ עמודות חלבונים בלבד (לפי שמות השורות ב-G); החל np.log(x + 1e-6); הפוך לחלבונים × תאים
3 חישוב R²_full שחזר עם G_all × L_allᵀ; חשב R² לכל תא; קח ממוצע
4 זיהוי רכיבים נבחרים מתוך שורת הסקשן בטבלה, זהה עמודות G שאינן NaN (למשל G2, G5, G9)
5 חישוב R²_optimal שחזר עם G_selected × L_selectedᵀ; חשב R² לכל תא; קח ממוצע
6 שמירה שמור R²_full, R²_optimal, ΔR² לטבלת הפלט

הקוד המלא

הרץ את הקוד הבא ב-Google Colab לאחר שטענת את טבלת התוצאות:

import pandas as pd import numpy as np import os, re BASE_PATH = '/content/drive/MyDrive/Rachel/TME project/DATA/all patients (without isotope)' results_df = pd.read_excel('Optimal_ES_Result.xlsx', sheet_name='Best_Combination_Details') es_columns = [c for c in results_df.columns if c.startswith('ES')] EPSILON = 1e-6 def compute_r2(X_log, G, L): X_hat = G @ L.T # שחזור: חלבונים × תאים r2_list = [] for j in range(X_log.shape[1]): x = X_log[:, j] y = X_hat[:, j] ss_res = np.sum((x - y) ** 2) ss_tot = np.sum((x - np.mean(x)) ** 2) r2 = 1 - ss_res / ss_tot if ss_tot != 0 else np.nan r2_list.append(r2) return np.nanmean(r2_list) output_rows = [] for _, row in results_df.iterrows(): roi_id = row['ROI'] patient = row['Patient'] roi_folder = roi_id.replace(patient + '_', '') sa_path = os.path.join(BASE_PATH, patient, roi_folder, 'surprisal analysis') data_path = os.path.join(BASE_PATH, patient, roi_folder, f'{roi_id}.xlsx') df_g = pd.read_excel(sa_path + '/G.xlsx', index_col=0) df_l = pd.read_excel(sa_path + '/L.xlsx', index_col=0) df_raw = pd.read_excel(data_path) proteins = df_g.index.tolist() X_raw = df_raw[proteins].values # תאים × חלבונים X_log = np.log(X_raw + EPSILON).T # חלבונים × תאים G_all = df_g.loc[proteins].values L_all = df_l.values r2_full = compute_r2(X_log, G_all, L_all) selected = sorted({ int(re.search(r'G(\d+)', str(row[c])).group(1)) for c in es_columns if pd.notna(row[c]) and re.search(r'G(\d+)', str(row[c])) }) r2_opt = compute_r2(X_log, G_all[:, selected], L_all[:, selected]) output_rows.append({ 'ROI': roi_id, 'Patient': patient, 'N_cells': X_log.shape[1], 'R2_full': round(r2_full, 4), 'R2_optimal': round(r2_opt, 4), 'Delta_R2': round(r2_full - r2_opt, 4), 'N_selected': len(selected), }) print(f'{roi_id}: full={r2_full:.3f} | opt={r2_opt:.3f} | Δ={r2_full - r2_opt:.3f}') pd.DataFrame(output_rows).to_excel('R2 comparison per ROI.xlsx', index=False)
